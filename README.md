# Machine Learning Based Compiler Error Classification

## Project Description
This project focuses on detecting and classifying compiler errors such as:
- Lexical Errors
- Syntax Errors
- Semantic Errors

The system analyzes input source code and identifies different error categories.

## Technologies
- C++
- Machine Learning (future phase)
- GitHub for version control

## Project Modules
1. Lexical Analyzer
2. Syntax Checker
3. Semantic Analyzer
4. Error Classifier

## How to Run

Compile the project:

g++ main.cpp lexical_analyzer.cpp syntax_checker.cpp semantic_checker.cpp error_classifier.cpp -o compiler

Run:

./compiler
